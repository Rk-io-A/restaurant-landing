# Restaurant & Cafe Landing Page

Responsive restaurant landing-page portfolio demo focused on menu presentation and reservation-conversion UI.

> **Demo only:** reservation forms and business details are illustrative unless connected to a verified restaurant backend.

## Purpose

Demonstrates responsive marketing layout, menu/service presentation and reservation-focused calls to action.

## Deployment

Static / GitHub Pages compatible.

A real deployment should validate reservation requests server-side, protect customer contact data and clearly show whether a reservation is confirmed or only requested.
